# Financial Aurora v1.0.1 发布说明

发布日期：2026-11-06。

## 本版变化

整车多视角环绕增加地面阴影。根据各视角的车轮接地点和车身投影范围，叠加底盘柔影与较深的轮胎接触阴影；视角切换时，阴影与车辆共用同一动画进度。光照方向固定，避免阴影像装饰圆盘一样自行旋转。

阴影采用程序绘制，属于配合透明多视角图片的投影近似，并非三维模型光线追踪。保留既有像素分解与重聚、暂停、手动切换、减少动态效果设置和独立 BOM 系统展示。

本次未修改业务数据、财务计算、采购配件名称、SKU、BOM 源表或浏览器存储键。

## 更新方式

1. 使用 `Financial-Aurora-v1.0.1-deploy.zip` 更新网站文件，解压根目录即 `index.html`。
2. 刷新页面缓存，进入首页“整车成本与概览”查看。
3. 图片文件与 v1.0.0 完全相同，继续使用 `https://cdn.aurora-racing.com/financial-aurora/v1.0.0/assets/`。若此前已上传该图片包，无需重传图片。

完整图片包继续随版本提供，便于首次部署；其中 `assets/` 仍上传到七牛 `financial-aurora/v1.0.0/` 前缀。源码包和 GitHub `v1.0.1` 标签对应本版，校验值见 `SHA256SUMS.txt`。

保持原站协议、域名和端口即可沿用原浏览器数据；升级不需要重置工作区。迁移到新域名或设备时，按首次发布说明导出并导入工作区备份。

## 验证

本版针对阴影同步、暂停、切换、缩放、移动端、BOM 独立性与数据保留进行验收，结果见 `docs/VERIFICATION-v1.0.1.md`。图片 CDN 上传与生产域名可达性仍由部署方核验；静态包测试不代表真实 CDN 已上线。
