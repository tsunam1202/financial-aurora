# Financial Aurora v1.0.0 发布说明

发布日期：2026-11-05。项目：Financial Aurora 财务网站。此版本为独立静态站发布，不替换 Performance Lab 整站。

## 交付文件

- `Financial-Aurora-v1.0.0-deploy.zip`：部署包，解压根目录即 `index.html`，包含 CSS、JavaScript、字体及运行所需数据，不包含图片。
- `Financial-Aurora-v1.0.0-images.zip`：完整图片包，保留 `assets/` 层级，包含商品、车队 Logo、整车多视角及 BOM 部件素材。
- `Financial-Aurora-v1.0.0-source.zip`：独立源码、完整本地素材和可重现打包脚本；不是部署包。
- 本说明、校验清单，以及 GitHub 仓库 `tsunam1202/financial-aurora` 的 `v1.0.0` 标签。

## 本版内容

- 保留紫色玻璃风格、放大的资金圆圈、按时间聚焦的收付款图表和三个首页板块轮播。
- 保留抠图赛车多视角环绕、像素分解与重聚，以及 BOM 系统探索和高亮成本环形图。
- 统一业务页面样式，保留财务、报销、采购、库存、SKU 与销售、工资、研发、预算、报表和设置。
- 将依赖的商品目录、联动桥接脚本移入独立项目，不再依赖原站相邻的 `dist/` 文件夹。
- 集中配置图片 CDN 根地址，正式部署与本地开发素材分开。

## 七牛图片上传

本次包含新图片，不能直接沿用 Performance Lab 已上传的 `v5.0.0` 图片目录。独立财务项目采用独立命名空间：

```text
https://cdn.aurora-racing.com/financial-aurora/v1.0.0/assets/
```

将图片 ZIP 解压后，把整个 `assets/` 上传到七牛对象前缀 `financial-aurora/v1.0.0/`。例如包内 `assets/aurora-logo.png` 的完整访问地址应为：

```text
https://cdn.aurora-racing.com/financial-aurora/v1.0.0/assets/aurora-logo.png
```

不要重复嵌套为 `assets/assets/`，不要覆盖 Performance Lab 的旧版本。完整素材包已包含沿用图片，不需要从旧目录另外补图。使用其他前缀时，应修改源码中的 `release.config.json` 并重新打包；无需手工逐页改地址。

**本任务未上传七牛。** 新 CDN 图片的线上可达性需要上传后最终复核。预发布 HTTP 验收使用图片包映射指定 CDN 请求，只验证路径与素材完整性，不能替代真实 CDN 上线验证。

## 静态服务器部署

1. 先上传图片，抽查 Logo、商品图和赛车透明图可以通过指定 CDN 地址打开。
2. 备份服务器现有站点文件，再把部署 ZIP 解压到目标网站根目录，或指定财务子目录；`index.html` 应直接位于该目录下。
3. 使用 HTTPS 打开页面并刷新。页面使用哈希路由，不需要额外路由重写；无需 Node 服务、数据库或新增环境变量。
4. 若开启 CSP，需要允许本域脚本/样式/字体/iframe、上述 CDN 图片源和页面已有内联样式/脚本及 data/blob 图片；根据浏览器控制台进行配置。没有 CSP 时不需要为本包新增配置。
5. 本版赛车粒子使用随脚本发布的预计算像素数据，赛车原图通过普通图片元素展示，不需要额外图片跨域读取权限。若将来改成直接从 CDN 图片读取像素或纹理，再相应配置七牛跨域许可。

字体随部署包本地加载，不依赖在线字体服务。图片加载失败或 WebGL 不可用时应按页面已有降级处理显示；建议使用当前桌面或移动浏览器。

## 数据保留与联动范围

- 源码中的 BOM 源表快照、SKU 名称、采购配件名称、财务计算和已有数据结构保留。BOM 赛事标准成本与实际采购付款分别计算。
- 收付款时间回放使用经授权编排的每日展示分布，月收付总额与台账一致；每日柱形不表示真实交易日期。原始收支流水和导出仍以台账记录为准。
- 本版为浏览器本地工作区，数据保存在当前浏览器的 localStorage，GitHub 源码和部署包不包含用户浏览器里的个人录入数据。
- 更新文件前，请在原财务页面的管理设置导出完整 JSON 备份。相同协议、域名、端口下升级沿用原存储键；迁移域名、端口、浏览器或从 `file://` 改为 HTTPS 后，应在新站通过管理设置导入备份，不能仅复制网站文件就迁移数据。
- 本地存储键继续使用 `financial-aurora-workspace-v1`、`aurora-bom-planning-v1` 和 `aurora-commerce-link-v1`。不要把“重置工作区”当作升级步骤。
- 与 Performance Lab 同源部署时，可继续共享同一浏览器中的商城报价需求和公开库存，例如部署到 `https://lab.aurora-racing.com/financial-aurora/`。仅域名后缀相同但子域不同也不算同源。
- 独立域名部署时，内部财务/SKU 功能仍可运行，但不会自动跨域同步商城订单或库存。商城的“财务管理”返回入口也需要在商城项目内另行指向实际财务地址；本次未更改商城项目。
- 飞书真实审批、银行支付、跨设备云同步和服务端多人事务尚未接入。本版无新增后端，不作为正式法定会计总账或税务申报系统。

## 验收范围

发布前将检查解压后的 HTTP 运行、桌面和手机布局、各业务路由、BOM 与 SKU 数据、表单交互和本地存储，以及部署包文件组成。具体结果见源码内 `docs/VERIFICATION.md`。

上传七牛后还需打开真实部署地址完成一次图片、跨域权限和页面交互复核。
