# Financial Aurora v1.0.0 发布验收

验收日期：2026-11-05。测试对象为实际交付 ZIP 独立解压后的文件，通过临时 HTTP 静态服务器加载；没有依赖原项目相邻目录或本地集成服务器。

## 结果

- 压缩包检查：11 项通过。部署包 43 个文件，图片包 84 张图片。
- 浏览器检查：145 项通过。桌面 1920×1080、手机 390×844；首页加 15 个业务页面，共 32 次页面检查。
- 图片完整性：图片包全部 84 张图片通过浏览器解码；8 个 BOM 系统的整车叠加图和独立部件图均可加载。
- 没有 JavaScript 运行错误、控制台错误、HTTP 错误或资源请求失败；页面无水平溢出。桌面首页的 BOM 与整车区域完整位于首屏内。

## 已验证的交互与数据

- 三组首页内容可手动切换，并按顺序自动轮播；收付款时间轴自动向前聚焦。
- 整车使用 WebGL 粒子绘制，测试时粒子数量 30,611，实际绘制帧数持续增加；10 张透明多视角图均已解码。没有仅以静态图片替代粒子动画来通过测试。
- 点击 BOM 环图进入独立系统展示，8 个系统可切换；右侧整车展示保持独立。
- 采购、库存、销售、工资表单可以打开并取消；BOM 零件表与来源明细可以打开。
- 导航、视觉交互、打开与取消表单后，业务与 BOM 工作区存储保持一致；刷新后数据仍保留，哈希路由可直接恢复。
- 同源报价桥接 iframe 可完成需求创建、读取和发布状态更新，库存列表保持一致。此项使用单独的临时浏览器上下文，不写入用户工作区。
- 商品目录保留原始 60 项；财务初始工作区含 63 个 SKU（加上原有的 3 个本地 SKU）。BOM 已计价合计保持 `214092.990989093`，页面显示为 ¥214,092.99。

## 资源与上线边界

所有页面图片请求均指向 `https://cdn.aurora-racing.com/financial-aurora/v1.0.0/assets/`。预发布测试拦截该地址，并返回完整图片包中对应文件的原始字节，因此已验证 URL 与素材映射、图片解码及交互，但**没有验证这些新地址在七牛线上已存在**。

七牛上传、真实域名 HTTPS、服务器缓存与生产 CSP 需要部署后复核。本次未执行飞书真实审批、银行付款、后端跨设备同步或正式会计申报测试。当前车辆粒子直接使用预计算数据，普通图片展示不需要额外跨域像素读取权限。

部署包不包含图片、`.git`、`node_modules`、测试截图、本地服务工具或账户配置。全部测试使用隔离的浏览器上下文，未读取用户浏览器内的录入数据。
