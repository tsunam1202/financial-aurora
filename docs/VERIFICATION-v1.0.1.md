# Financial Aurora v1.0.1 阴影更新验收

验收日期：2026-11-06。范围：整车环绕的程序化地面阴影及其与已有页面的兼容性。

## 浏览器验收

- 原工作目录通过 file:// 打开：44 项检查全部通过。
- 独立部署包通过临时 HTTP 服务打开：44 项检查全部通过。
- 两组测试均无页面脚本错误、控制台错误或缺失资源。
- 十个视角的 Canvas 实际透明度图样各不相同，均有可见阴影；阴影与车辆使用同一过渡进度。
- 验证暂停、手动前后切换、减少动态效果、隐藏轮播、暂停停留时缩放和暂停过渡时缩放。
- 验证 BOM 系统展示独立运行，浏览器业务和 BOM 存储在交互前后保持一致。
- 检查 1920×1080、1366×768、390×844 布局；目视核验左前、侧面、正后与粒子过渡截图，以及同帧开关阴影对比。

两组测试的阴影绘制调用耗时 p95 均约 0.40 ms。这是测试机器上的 CPU 调用计时，不代表完整 GPU 帧耗时或其他设备性能保证。测试使用隔离浏览器上下文，没有读取或修改用户当前浏览器的私人录入。

## 文件与数据保留

- 部署包仍为 43 个文件，不包含图片。
- 运行文件仅变更 `js/vehicle-showcase.js`、`css/vehicle-showcase.css` 和版本配置 `js/release-config.js`。
- 其余运行文件与 v1.0.0 的 SHA-256 一致；业务数据、采购名称、SKU、财务计算与 BOM 数据均未修改。
- 整车脚本中独立 BOM 展示部分与旧版逐字节相同。
- 84 张图片与旧版逐字节相同，继续使用原 CDN 路径。
- 构建器逐项读回验证压缩包内容；最终文件 SHA-256 见交付包校验清单。

## 验证边界

预发布 HTTP 测试将指定 CDN 图片请求映射到完整图片包，验证路径、素材和浏览器行为；未上传七牛，也未证明生产 CDN 地址已可访问。此更新为基于多视角抠图校准的投影近似，没有增加三维模型或光线追踪引擎。

本次没有重新执行与阴影无关的全部业务流程验收；上一版的完整业务验收记录保留在 `VERIFICATION.md`。
